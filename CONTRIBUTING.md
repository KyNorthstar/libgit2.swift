# Guidelines for contributing



## On the use of auto-coding tools like LLMs

If you didn't write the code you're committing, you don't understand it.

That's not strictly true in all cases; you can understand something you're reading. However, for the purposes of this codebase and LLMs, we're going to consider it true.

Feel free to use these tools however you wish, but ensure that you fully understand their output before submitting it.

Try to stick to autocompletion of rote tasks, rather than having the tool write entire functions or more.

Be prepared to fully explain each choice you make in each contribution.
